# LUXE — Premium E-Commerce

A polished e-commerce frontend built from scratch with HTML, CSS and vanilla JavaScript.

## Features

- Responsive premium UI
- Product catalog
- Search
- Category filtering
- Sorting
- Product detail modal
- Shopping cart
- Quantity controls
- Wishlist
- LocalStorage persistence
- Newsletter validation
- GSAP entrance and scroll animations
- Reduced-motion support
- Empty and error-friendly states

## Stack

HTML5 · CSS3 · JavaScript · GSAP · LocalStorage

## Run

Open `index.html` in a browser, or serve the folder with a local development server.
